# Wazuh Threat Hunting Queries - Nikto & ModSecurity Web Attack Detection

Use these queries in **Threat Hunting -> Events** on the Wazuh Dashboard (`https://192.168.80.132`) to isolate and analyze web scanning and WAF detection alerts.

## 1. Filter Target Web Server Agent

Select events from the agent hosting the web service (`ubuntu-server`, ID `001`):

```text
agent.name:"ubuntu-server"
```

## 2. All Web Server Events (Group Filter)

Filter all alerts categorized under the `web`, `accesslog`, and `attack` rule groups:

```text
agent.name:"ubuntu-server" AND rule.groups:"web"
```

## 3. Web Server 400 Error Codes (Rule 31101)

Query for HTTP 400/404 error codes generated by Nikto fuzzing and scanning:

```text
agent.name:"ubuntu-server" AND rule.id:31101
```

## 4. ModSecurity WAF Detection Alerts

Filter all events detected and logged by the ModSecurity engine:

```text
agent.name:"ubuntu-server" AND rule.groups:"modsecurity"
```

## 5. Filter by Attacker Source IP

Isolate all events originating from the attacker host (Kali Linux `192.168.80.130`):

```text
agent.name:"ubuntu-server" AND data.srcip:"192.168.80.130"
```

## 6. Combine Attacker IP & Web Attack Group

```text
agent.name:"ubuntu-server" AND data.srcip:"192.168.80.130" AND rule.groups:"attack"
```
